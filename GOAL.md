# Pilot Wave simulator
Simulation of a pilot wave that can replicate several quantum effects shown in real laboratory experiments.

Engine: A shared pilot wave engine in 2D that can compute the time evolution of an initial state.

Experiments:
A set of clear experiment setups and their expected outcomes. These should be easy to verify against the relevant scientic paper describing the real life experiment.
These experiments maybe run using arbritary scales/units for optimal numerical stability and accuracy, but conversion factors should be noted to convert back to real-life units. (SI)

The goal is to have a few solid experiments

Visualization: To be able to visualize, in still or moving pictures, beautiful replays of these experiments.

Non-goals: Stochastic quantum mechanics, curved space solutions
